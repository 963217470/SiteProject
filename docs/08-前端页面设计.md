# 八、前端页面设计

## 8.1 页面总览

| 页面 | 路由 | 说明 | 访问权限 |
|------|------|------|----------|
| 首页 | `/` | 门户页面 | 游客可访问 |
| 文章列表 | `/articles` | 所有文章 | 游客可访问 |
| 文章详情 | `/articles/:id` | 阅读文章 | 游客可访问（内部文章需登录） |
| 内部文章 | `/internal` | 内部文章 | 社员/管理员 |
| 作品展示 | `/works` | 社团作品 | 游客可访问 |
| 关于我们 | `/about` | 社团介绍 | 游客可访问 |
| 登录 | `/login` | GitHub 登录 | 游客 |
| 邀请加入 | `/invite/:code` | 通过邀请链接加入 | 游客 |
| **用户主页** | `/user/:id` | 用户个人主页 | 游客可访问 |
| **个人设置** | `/user/settings` | 编辑个人资料 | 已登录用户 |
| 后台管理 | `/admin` | 管理后台 | 管理员 |
| 编辑文章 | `/admin/editor/:id?` | 编辑/新建文章 | 社员/管理员 |
| 审核队列 | `/admin/review` | 待审核文章 | 管理员 |
| 用户管理 | `/admin/users` | 管理用户 | 管理员 |

## 8.2 页面跳转逻辑

```
┌─────────────────────────────────────────────────────────────┐
│                        页面跳转流程                          │
└─────────────────────────────────────────────────────────────┘

游客访问网站
      │
      ▼
┌─────────────┐
│    首页     │ ← 默认落地页
└──────┬──────┘
       │
       ├──→ [文章列表] ──→ [文章详情]
       │
       ├──→ [作品展示]
       │
       ├──→ [关于我们]
       │
       ├──→ [用户主页] ──→ 查看用户文章
       │
       └──→ [登录] ──→ GitHub OAuth ──→ 返回原页面
                │
                ▼
         ┌─────────────┐
         │  已登录用户  │
         └──────┬──────┘
                │
                ├──→ [个人设置] ──→ 修改头像/昵称/简介（需审核）
                │
                ├──→ [我的文章] ──→ 草稿/已发布/退回 分栏
                │
                ├──→ [内部文章]
                │
                ├──→ [点赞/评论]
                │
                └──→ [管理后台] (仅管理员)
                        │
                        ├──→ [文章管理]
                        ├──→ [编辑文章]
                        ├──→ [审核队列]
                        └──→ [用户管理]
```

## 8.5 权限控制

```typescript
// 路由守卫
router.beforeEach((to, from, next) => {
  const user = useUserStore()
  
  // 需要登录的页面
  if (to.meta.requiresAuth && !user.isLoggedIn) {
    return next({ path: '/login', query: { redirect: to.fullPath } })
  }
  
  // 需要特定角色的页面
  if (to.meta.role && user.role !== to.meta.role) {
    return next('/')  // 或显示无权限页面
  }
  
  next()
})
```
