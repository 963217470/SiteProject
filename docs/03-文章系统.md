# 三、文章系统

## 3.1 文章类型

本系统仅支持一种文章类型：**技术分享**

所有文章均为游戏开发相关的技术内容，不区分分类。

## 3.2 标签系统（完全预设）

一篇文章可以有多个标签，标签不可自定义。

### 引擎/工具标签

| 标签 | 说明 |
|------|------|
| Unity | Unity 引擎相关 |
| Godot | Godot 引擎相关 |
| Unreal Engine | UE 引擎相关 |
| Cocos Creator | Cocos 引擎相关 |
| C# | C# 编程语言 |
| GDScript | GDScript 编程语言 |
| C++ | C++ 编程语言 |
| Lua | Lua 脚本语言 |
| Blender | 3D 建模 |
| Aseprite | 像素画制作 |

### 内容类型标签

| 标签 | 说明 |
|------|------|
| 教程 | 详细的教学文章 |
| 入门 | 新手向内容 |
| 进阶 | 进阶技巧 |
| Game Jam | Game Jam 活动相关 |
| 团队合作 | 团队协作经验 |
| 个人项目 | 个人作品分享 |

### 主题标签

| 标签 | 说明 |
|------|------|
| 2D游戏 | 2D 游戏开发 |
| 3D游戏 | 3D 游戏开发 |
| 像素风 | 像素风格游戏 |
| 音频制作 | 游戏音频 |
| UI设计 | 游戏界面设计 |
| 游戏策划 | 游戏设计文档 |

## 3.2 文章 Frontmatter

```yaml
---
title: "文章标题"
date: 2024-01-15
author: "作者名"
tags: ["Unity", "2D游戏", "教程"]
visibility: "public"  # public | internal
cover: "./images/cover.jpg"  # 封面图
summary: "文章摘要文字，显示在文章列表中"  # 摘要
---

# 文章标题

正文内容...
```

## 3.3 文章目录结构

```
docs/
├── articles/
│   ├── public/           # 公开文章
│   │   ├── 2024-01-unity-lighting.md
│   │   └── 2024-01-game-jam.md
│   └── internal/         # 内部文章（需登录）
│       ├── meeting-0105.md
│       └── unreal-notes.md
└── ...
```

## 3.5 文章状态

| 状态 | 说明 | 可见性 |
|------|------|--------|
| draft | 草稿 | 仅作者 |
| pending | 待审核 | 作者 + 管理员 |
| published | 已发布 | 根据 visibility 设置 |
| rejected | 审核未通过 | 作者 + 管理员 |
