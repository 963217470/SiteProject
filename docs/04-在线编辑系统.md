# 四、在线编辑系统（Tiptap 块编辑器）

## 4.1 方案说明

使用 Tiptap 实现类似飞书/Notion 的所见即所得编辑器。

### 技术架构

```
┌─────────────────────────────────────────────────────────────┐
│                      用户界面                                │
├─────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────┐   │
│  │              Tiptap Editor                          │   │
│  │         （所见即所得块编辑器）                         │   │
│  └─────────────────────────────────────────────────────┘   │
│                           │                                 │
│                           ▼                                 │
│  ┌─────────────────────────────────────────────────────┐   │
│  │              API 服务层                              │   │
│  │  - 保存文章（转为 Markdown）                         │   │
│  │  - 提交审核                                         │   │
│  │  - 用户认证                                         │   │
│  └─────────────────────────────────────────────────────┘   │
│                           │                                 │
│                           ▼                                 │
│  ┌─────────────────┐  ┌─────────────────┐                  │
│  │    Supabase     │  │     GitHub      │                  │
│  │   （用户认证）   │  │  （存储 Markdown）│                  │
│  └─────────────────┘  └─────────────────┘                  │
└─────────────────────────────────────────────────────────────┘
```

### 为什么选 Tiptap

| 对比项 | Tiptap | Decap CMS |
|--------|--------|-----------|
| 编辑体验 | ⭐⭐⭐ 所见即所得 | ⭐⭐ Markdown 分屏 |
| 学习成本 | ⭐ 零门槛 | ⭐⭐ 需了解 Markdown |
| 开发成本 | 3-5 天 | 1 天（配置） |
| 数据存储 | GitHub（Markdown） | GitHub（Markdown） |
| 自定义能力 | ⭐⭐⭐ 完全可控 | ⭐⭐ 受限 |

### 编辑器组件示例

```vue
<!-- components/editor/TiptapEditor.vue -->
<template>
  <div class="editor-container">
    <!-- 工具栏 -->
    <MenuBar :editor="editor" />
    
    <!-- 编辑器内容 -->
    <EditorContent :editor="editor" />
  </div>
</template>

<script setup>
import { useEditor, EditorContent } from '@tiptap/vue-3'
import StarterKit from '@tiptap/starter-kit'
import ImageUpload from './extensions/ImageUpload'
import CodeBlock from './extensions/CodeBlock'

const props = defineProps({
  modelValue: String
})

const emit = defineEmits(['update:modelValue'])

const editor = useEditor({
  content: props.modelValue,
  extensions: [
    StarterKit,
    ImageUpload,
    CodeBlock
  ],
  onUpdate: ({ editor }) => {
    // 导出为 Markdown
    const markdown = editor.storage.markdown.getMarkdown()
    emit('update:modelValue', markdown)
  }
})
</script>
```

### 数据存储

```typescript
// 存储文章到 GitHub
async function saveArticle(article: Article) {
  const markdown = convertToMarkdown(article)
  
  // 通过 API 保存到 GitHub
  await fetch('/api/articles', {
    method: 'POST',
    body: JSON.stringify({
      title: article.title,
      content: markdown,
      tags: article.tags,
      visibility: article.visibility,
      status: article.status
    })
  })
}

// 转换为 Markdown 格式
function convertToMarkdown(article: Article): string {
  return `---
title: "${article.title}"
date: ${article.date}
author: "${article.author}"
tags: [${article.tags.map(t => `"${t}"`).join(', ')}]
visibility: "${article.visibility}"
---

${article.content}
`
}
```

### GitHub API 操作

```typescript
// 通过 GitHub API 保存文件
async function saveToGitHub(path: string, content: string) {
  const encoded = btoa(unescape(encodeURIComponent(content)))
  
  await fetch(
    `https://api.github.com/repos/${REPO}/${path}`,
    {
      method: 'PUT',
      headers: {
        Authorization: `token ${GITHUB_TOKEN}`,
        'Content-Type': 'application/json'
      },
      body: JSON.stringify({
        message: `feat: 添加文章 ${path}`,
        content: encoded
      })
    }
  )
}
```
