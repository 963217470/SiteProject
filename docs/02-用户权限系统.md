# 二、用户权限系统

## 2.1 角色定义

| 角色 | 说明 | 获取方式 |
|------|------|----------|
| **游客** | 未登录访客 | - |
| **社员** | 社团成员 | 邀请链接注册 或 管理员手动添加 |
| **管理员** | 社团管理员 | 管理员手动添加 |

## 2.2 登录方式

仅支持 **GitHub 登录**，强制所有用户使用 GitHub 账号。

| 登录方式 | 说明 |
|----------|------|
| GitHub OAuth | 唯一登录方式 |

## 2.4 升级机制

### 方式一：邀请链接

```
管理员生成邀请链接
         ↓
分享给新社员（链接格式：https://site.com/invite/abc123）
         ↓
新社员点击链接
         ↓
    ┌─────────────────────────────────────┐
    │  是否已登录？                        │
    │                                     │
    │  是 → 弹出确认界面，显示用户名       │
    │        用户点击「确认」→ 成为社员    │
    │                                     │
    │  否 → 弹出 GitHub 登录界面          │
    │        登录/注册后 → 成为社员        │
    └─────────────────────────────────────┘
         ↓
链接使用后立即销毁（一次性）
```

### 方式二：管理员手动添加

```
管理员登录后台 → 用户管理 → 搜索用户 → 修改角色为「社员」
```

## 2.5 邀请链接设计

### 链接格式

```
https://your-site.com/invite/{unique_code}
```

### 数据库设计

```sql
-- 邀请链接表
CREATE TABLE invite_links (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  created_by UUID REFERENCES profiles(id),
  used_by UUID REFERENCES profiles(id),
  used_at TIMESTAMP WITH TIME ZONE,
  expires_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 使用后标记
UPDATE invite_links 
SET used_by = $1, used_at = NOW() 
WHERE code = $2 AND used_by IS NULL;
```

### 前端交互流程

```vue
<!-- pages/invite/[code].vue -->
<template>
  <div class="invite-page">
    <!-- 已登录：显示确认界面 -->
    <div v-if="user" class="confirm-box">
      <h2>确认加入社团</h2>
      <p>当前账号：<strong>{{ user.username }}</strong></p>
      <p>点击确认后，您将获得社员权限</p>
      <button @click="confirmJoin" :disabled="loading">
        {{ loading处理中...' : '确认加入' }}
      </button>
    </div>
    
    <!-- 未登录：显示登录界面 -->
    <div v-else class="login-box">
      <h2>登录以加入社团</h2>
      <GitHubLoginButton @login="handleLogin" />
    </div>
    
    <!-- 错误提示 -->
    <div v-if="error" class="error">
      {{ error }}
    </div>
  </div>
</template>

<script setup>
const route = useRoute()
const user = useUserStore()
const code = route.params.code

async function confirmJoin() {
  // 调用 API 确认加入
  const res = await fetch('/api/invite/confirm', {
    method: 'POST',
    body: JSON.stringify({ code })
  })
  
  if (res.success) {
    // 链接已销毁，跳转到首页
    navigateTo('/')
  }
}

async function handleLogin() {
  // GitHub 登录后自动处理邀请
  const res = await fetch('/api/invite/use', {
    method: 'POST',
    body: JSON.stringify({ code })
  })
}
</script>
```

## 2.6 数据库设计（Supabase）

```sql
-- 用户表（Supabase Auth 自动创建）
-- auth.users {
--   id: uuid
--   email: string
--   user_metadata: { avatar_url, full_name }
--   created_at: timestamp
-- }

-- 用户资料表（需要创建）
CREATE TABLE profiles (
  id UUID REFERENCES auth.users(id) PRIMARY KEY,
  username TEXT,
  avatar_url TEXT,
  role TEXT CHECK (role IN ('member', 'admin')) DEFAULT 'member',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- 邀请链接表
CREATE TABLE invite_links (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  code TEXT UNIQUE NOT NULL,
  created_by UUID REFERENCES profiles(id),
  used_by UUID REFERENCES profiles(id),
  used_at TIMESTAMP WITH TIME ZONE,
  expires_at TIMESTAMP WITH TIME ZONE,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

-- RLS 策略
ALTER TABLE profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE invite_links ENABLE ROW LEVEL SECURITY;

-- 用户只能查看自己的资料
CREATE POLICY "Users can view own profile" ON profiles
  FOR SELECT USING (auth.uid() = id);

-- 管理员可以查看所有资料
CREATE POLICY "Admins can view all profiles" ON profiles
  FOR SELECT USING (
    EXISTS (
      SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'
    )
  );

-- 管理员可以更新用户角色
CREATE POLICY "Admins can update roles" ON profiles
  FOR UPDATE USING (
    EXISTS (
      SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'
    )
  );

-- 管理员可以创建邀请链接
CREATE POLICY "Admins can create invites" ON invite_links
  FOR INSERT WITH CHECK (
    EXISTS (
      SELECT 1 FROM profiles WHERE id = auth.uid() AND role = 'admin'
    )
  );

-- 用户可以使用未使用的邀请链接
CREATE POLICY "Anyone can use valid invite" ON invite_links
  FOR UPDATE USING (
    used_by IS NULL AND expires_at > NOW()
  );
```
