# 五、评论与点赞系统

## 5.1 评论系统（Giscus）

### 方案说明

使用 Giscus 实现评论功能，基于 GitHub Discussions，完全免费。

### 功能特点

| 特点 | 说明 |
|------|------|
| 免费 | 基于 GitHub Discussions |
| 无需后端 | 直接使用 GitHub 存储 |
| 支持 Markdown | 评论支持 Markdown 格式 |
| 通知 | 通过 GitHub 通知 |
| 管理 | 通过 GitHub 管理评论 |

### 访问权限

| 角色 | 评论权限 |
|------|----------|
| 游客 | ❌ 不能评论 |
| 用户 | ✅ 可以评论 |
| 社员 | ✅ 可以评论 |
| 管理员 | ✅ 可以评论 + 删除评论 |

### 集成方式

```vue
<!-- components/CommentSection.vue -->
<template>
  <div class="comment-section">
    <!-- 未登录提示 -->
    <div v-if="!user" class="login-prompt">
      <p>登录后即可评论</p>
      <button @click="login">登录</button>
    </div>
    
    <!-- 已登录显示 Giscus -->
    <Giscus
      v-else
      repo="your-org/game-dev-club"
      repoId="your-repo-id"
      category="Announcements"
      categoryId="your-category-id"
      mapping="pathname"
      reactionsEnabled="1"
      emitMetadata="0"
      inputPosition="top"
      theme="dark"
      lang="zh-CN"
    />
  </div>
</template>

<script setup>
import { useUserStore } from '~/stores/user'

const user = useUserStore()
</script>
```

## 5.2 点赞系统

### 方案说明

自定义实现，仅记录点赞数量，数据存储在 JSON 文件中。

### 数据结构

```json
// data/likes.json
{
  "articles/public/2024-01-unity-lighting.md": {
    "count": 128,
    "users": ["user1", "user2", "user3"]
  },
  "articles/public/2024-01-game-jam.md": {
    "count": 89,
    "users": ["user1", "user4"]
  }
}
```

### 访问权限

| 角色 | 点赞权限 |
|------|----------|
| 游客 | ❌ 不能点赞 |
| 用户 | ✅ 可以点赞 |
| 社员 | ✅ 可以点赞 |
| 管理员 | ✅ 可以点赞 |

### API 设计

```
POST /api/likes
{
  "articlePath": "articles/public/2024-01-unity-lighting.md"
}

Response:
{
  "success": true,
  "newCount": 129
}

DELETE /api/likes
{
  "articlePath": "articles/public/2024-01-unity-lighting.md"
}

Response:
{
  "success": true,
  "newCount": 128
}
```

### 前端组件

```vue
<!-- components/LikeButton.vue -->
<template>
  <button 
    class="like-button"
    :class="{ liked: isLiked }"
    @click="toggleLike"
    :disabled="!user"
  >
    <span class="icon">❤️</span>
    <span class="count">{{ likeCount }}</span>
  </button>
</template>

<script setup>
import { ref, onMounted } from 'vue'
import { useUserStore } from '~/stores/user'

const props = defineProps({
  articlePath: String
})

const user = useUserStore()
const likeCount = ref(0)
const isLiked = ref(false)

onMounted(async () => {
  await fetchLikes()
})

async function fetchLikes() {
  const res = await fetch(`/api/likes?path=${props.articlePath}`)
  const data = await res.json()
  likeCount.value = data.count
  isLiked.value = data.userLiked
}

async function toggleLike() {
  if (!user) return
  
  if (isLiked.value) {
    await fetch(`/api/likes`, {
      method: 'DELETE',
      body: JSON.stringify({ articlePath: props.articlePath })
    })
  } else {
    await fetch(`/api/likes`, {
      method: 'POST',
      body: JSON.stringify({ articlePath: props.articlePath })
    })
  }
  
  await fetchLikes()
}
</script>
```

## 5.3 实现方式选择

### 方案 A：GitHub Actions + JSON 文件（推荐）

```
用户点赞 → 调用 API → 修改 JSON 文件 → 提交到 GitHub → 自动部署
```

**优点**：
- 简单，无需后端
- 数据持久化

**缺点**：
- 部署有延迟（几分钟）
- 并发冲突风险

### 方案 B：Supabase 数据库

```
用户点赞 → 调用 API → 写入 Supabase → 实时更新
```

**优点**：
- 实时更新
- 无部署延迟

**缺点**：
- 需要额外配置 Supabase

### 方案 C：LocalStorage + 后端同步

```
用户点赞 → 本地存储 → 定时同步到后端
```

**优点**：
- 即时响应

**缺点**：
- 换设备数据丢失
- 实现复杂

**推荐方案 A**，简单可靠，对于社团网站足够。
