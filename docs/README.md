# RD STUDIO 项目文档

本页是项目文档总入口。接手项目时先读“现行基线”，开发时从 `DevPlan/` 领取任务；编号专题文档包含早期方案和产品设计，若与代码或白皮书冲突，以代码、迁移、CI 和 Task 验证记录为准。

## 运行页面

页面源码直接位于 `docs/`，由 VitePress 文件路由生成。主要入口包括：首页、文章列表与详情、编辑器、知识库、内部资源、用户资料与设置、登录与 OAuth 回调、管理员首页/知识库/资料审核。

## 文档约定

- 现状必须能对应源码、SQL、测试或 CI 配置。
- 规划内容必须明确标注“规划中”，不能写成已经上线。
- 示例只能使用占位值，禁止记录真实 key、token、密码或用户数据。
- 架构决策使用 `docs/architecture/adr/` 中的 ADR 模板。
- 路由、脚本、环境变量和 Node 版本变化时，同步更新 README 与白皮书。
