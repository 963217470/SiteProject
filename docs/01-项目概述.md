# 一、项目概述

## 1.1 需求概述

| 需求 | 说明 |
|------|------|
| 门户页面 | 展示社团介绍、最新动态、作品展示 |
| 文章发布 | 社员通过在线编辑或 Git 发布文章 |
| 访问控制 | 文章分「公开」和「内部可见」两种 |
| 用户系统 | 游客/用户/社员/管理员四种角色 |
| 低成本 | 优先使用免费服务 |

## 1.2 技术选型

| 组件 | 方案 | 说明 |
|------|------|------|
| 静态生成 | VitePress | Vue 驱动，开发体验好 |
| 部署平台 | GitHub Pages | 免费，自带域名 |
| 在线编辑 | Decap CMS | 可视化编辑，类似飞书 |
| 用户认证 | Supabase Auth | 免费 5万用户/月 |
| 评论系统 | Giscus | 基于 GitHub Discussions |
| 版本控制 | GitHub | 协作管理 |
