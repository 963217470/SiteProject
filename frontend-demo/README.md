# RD STUDIO 前端创作社区

## 运行

直接用浏览器打开 `index.html`。无需安装依赖、构建或连接服务器，图标库也已随源码提供。

若浏览器限制本地文件的存储，可以在本目录启动任意静态 HTTP 服务；例如安装了 Python 时执行 `python -m http.server 4176`，访问 `http://localhost:4176`。

## 内容与交互

- 响应式导航：首页、知识库、游戏 / 工具、社区、关于。
- 原创 Canvas 像素场景：慢速云、水面、角色眨眼，电脑端微幅视差；移出屏幕或后台时暂停。
- 三个快捷入口，三列作品展示，帖子列表与侧栏。
- 分类、关键词、热门排序、收藏筛选、作品及笔记详情弹窗。
- 工具区提供可下载的 Game Jam 规划模板、试玩反馈表和 CSS 调色板。
- 本地发帖、回复、点赞、收藏、个人资料和签到。数据保存在 `localStorage` 的 `rd-studio-demo-v1` 键中。
- 签到按北京时间每天一次，5 EXP，连续七天额外 5 EXP；这里只提供前端示例，不与正式网站账户关联。
- 键盘可操作的原生 dialog，焦点约束、Escape 关闭、点背景关闭。
- 一次性滚动淡入与短促交互反馈；响应系统 `prefers-reduced-motion`，手机不启用场景视差。

作品与社区成员为演示数据。没有真实注册、审核、下载文件或联网发布，也不连接现有网站的后端。本目录完全独立，未修改线上站点。

## 源码

`index.html` 为页面结构，`style.css` 为布局与动效，`scene.js` 为像素场景，`model.js` 为本地数据和规则，`app.js` 为界面交互。`vendor` 为固定版本 Lucide 0.577.0（含原许可证）。

修改示例帖子与作品可编辑 `model.js`，知识笔记在 `app.js` 的 `notes` 数组中。

## 验证

运行 `node --test model.test.cjs` 检查筛选、存储恢复、输入转义和签到规则。

`browser.test.cjs` 为可选 Playwright 测试，需要安装 Playwright 和 Microsoft Edge。已验证 320 / 390 / 768 / 1440 / 1920px 布局、场景非空与动画、减少动态效果、帖子和回复持久化、输入转义、签到及模板下载。页面本身无需这些测试依赖。
